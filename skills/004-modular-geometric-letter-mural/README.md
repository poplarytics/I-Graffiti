# Modular Geometric Letter Mural

Create flat aerosol word murals from large rounded modules, a selective dark painted scaffold, heavy overlap without individual letter edges, and fine lines that replace letter gaps. Use a compact reference-led palette; a contained tonal transition is optional and focal, not a default wash.

Use `$modular-geometric-letter-mural`. Read [SKILL.md](SKILL.md), then adapt [the prompt](prompt-chatgpt.md) or [examples](examples.md). Make original work without naming or imitating a source artist, composition, word, signature, tag, or mark.
