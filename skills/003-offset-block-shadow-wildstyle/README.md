# Offset Block-Shadow Wildstyle

Create a coherent modular graffiti word group with a second, large, displaced painted back layer. Wide arc-blocks, blocky bends, and selected square-capped broken terminals shape the foreground; the controlled offset establishes spatial misregistration without physical depth.
