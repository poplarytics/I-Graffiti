# Examples

## Zero input

**Request:** Use `$offset-block-shadow-wildstyle`.

**Expected:** An original `Graffiti` mural on a real carrier. Thick modular letters form one clear word group; a contrasting large displaced painted back layer provides organized misregistration; decoration is absent or limited to one subordinate star, cross-star, or flame-state motif.

## Supplied word

**Request:** Use `$offset-block-shadow-wildstyle` for the word `RHYTHM` on a weathered corrugated shutter.

**Expected:** `RHYTHM` remains a coherent word-level silhouette. Corrugation crosses foreground and back-layer paint; the offset system is broad and compositional rather than a narrow shadow.

## Optional ornament

**Request:** Use `$offset-block-shadow-wildstyle` for `NIGHT SHIFT`, with a single subtle flame-state motif.

**Expected:** The flame-state motif stays peripheral and smaller than all principal letter bodies. No extra slogan, character, source identifier, mechanical construction, or ribbon-flow system appears.
