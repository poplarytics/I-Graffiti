# Soft-Cell Freight Funk

Create original flat aerosol graffiti on real carriers from piled inflated soft cells, broad contained structural corridors, dark internal turns, and sparse grouped accents. One shallow connected word-band dominates; the upper and lower cell banks visibly interlock without resolving into evenly spaced bubble letters. Freight cars are optional carriers, not a requirement.
